#  Embedded Sensor Monitoring & Alert System (TRSE)

##  Description
Module logiciel C++ développé pour la simulation et la gestion des données de télémétrie (capteurs de température et de distance) destinées aux microcontrôleurs en systèmes embarqués.

## 🛠️ Spécifications Techniques
* **Langage :** C++11 / C++14
* **Domaine :** Systèmes Embarqués, Télémétrie, Algorithmique embarquée
* **Gestion d'états :** Machine à états finis pour la gestion des alertes critiques
